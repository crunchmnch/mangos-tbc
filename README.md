# crunchmnch WoW TBC Private Server

## Project Structure

- `custom/sql/install/` — Custom table definitions, run once on fresh builds
- `custom/sql/migrations/` — Sequential DB changes, numbered and never edited after commit
- `custom/config/` — Custom configuration overrides
- `docs/adr/` — Architecture Decision Records (what we decided and why)
- `docs/runbooks/` — Operational procedures
- `docs/design/` — Game mechanic specifications
